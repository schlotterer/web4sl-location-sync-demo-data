# Web4SL Location Sync demo data

Optional community records and photographs for demonstrating the Web4SL Location Sync directory. This repository contains demo content only; it is not a WordPress plugin.

The community names, contact details, descriptions and addresses are sample data, not a verified directory of real businesses. Images were extracted unchanged from the existing Web4SL Location Sync demo library. No plugin source code, credentials or customer records are included.

The import CSV and usage instructions are added in the dataset release. Plugin updates do not need to contain this image library.
